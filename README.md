# World of Wallhoppers - Devcade Gigagame

World of Wallhoppers (Also known as Gigagame) is a 2D Arcade platformer and racing game, made for the Devcade Arcade Cabinet

## Contributing to the Project

### Downloading Godot:
If you want to contribute to the project, you'll need to download Godot. Currently, the project uses Godot 4.7

To download Godot, first go to the Godot downloads page at: godotengine.org/downloads. The website will automatically bring you to the downloads page for your computer's platform.
Next, click the "Godot Engine" download button.
![Download Button Example](documentation/readme-images/download-page-button.png)
IMPORTANTLY, do not download the ".NET" version, as that uses C# alongside GDScript, which Gigagame is not built for.
After downloading Godot, it will just be an excecutable in a .zip file, which you can place wherever you wish

### Downloading the Project:

To download the project, you'll want to use Git to clone it. If you don't know how to use git, I'd reccomend Github desktop, as it's a GUI based off of git, which should help you learn how to use Git and Github. It can be downloaded at desktop.github.com/download.
Once Github Desktop is downloaded, you'll have to login to your Github account, which should be the one you want to use to contribute to the game.

You'll want to "clone" the project, which means you'll download a copy of the full repository (the project) to your computer.
